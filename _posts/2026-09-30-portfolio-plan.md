# Primary function

The primary function of the site is reprensenting my CV, including my education status, professional skills and experience, contact information and so on. The site’s target audiences consists of employers, recruiters and HR looking to evaluate my profile.

# Content

And it is expected to update the content of this website every month or week to reflect the progress of my personal projects. The content of this website is comprised of text and pictures. It may contain a video CV. Overall, the site is designed with a direct and efficient way. So primary ways to interact with this website are scrolling and clicking which fulfill the goal of helping viewers get to know me better.

# Budget

If the website is deployed on github pages, the budget for it will be free. Or if I want to add a customized domain to my github pages, it should cost no more than 10 euros per year.
