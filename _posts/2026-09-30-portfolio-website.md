# Primary function

The primary function of the site is for reprensenting my CV, including my education status, professional skills, experience, contact information and so on. The site’s target audiences are employers who might be interested in my information.

# Content

And it is expected to update the content of this website every month or week in step with the progress of my personal project. The content types of this website are mainly text or pictures. It may contain a video form of my CV. But other than that, it should be in a simple form which increse the efficiency of user interactions which are supposed to be direct and plain as well. So the primary ways to interact with this webiste are scrolling and clicking which should fulfill the goal of helping employers get to know me better.

# Budget

If the website will be deployed on github, the budget for it should be free. Or if I want to add a customized domain to my github pages, it should cost no more than 10 euro per year.
